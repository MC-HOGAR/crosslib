# Stack — crosslib (`@mc-hogar/crosslib`)

- TypeScript puro (sin runtime dependencies propias)
- Build: Babel (cjs + esm) + `tsc` para tipos (`dist/cjs`, `dist/esm`, `dist/types`)
- Test: Jest + ts-jest
- Lint: ESLint 9 + Prettier
- Publicación: paquete npm privado, versión actual 1.1.33 — bump de versión en cada cambio publicado (npm publish)
